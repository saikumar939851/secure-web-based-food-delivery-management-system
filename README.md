# Secure Web-Based Food Delivery Management System

## 📋 Project Overview
A role-based food delivery management platform built as an MCA capstone project. The system supports three user roles — **Admin**, **Restaurant**, and **Customer** — each with dedicated dashboards and permissions, enabling secure and organized food ordering and delivery management.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Database:** MySQL
- **Frontend:** HTML, CSS, Bootstrap 5
- **Authentication:** Role-based access control (Admin / Restaurant / Customer)

## ✨ Key Features
- Role-based authentication and authorization for Admin, Restaurant, and Customer
- Restaurant menu management (add, update, remove items)
- Customer cart and order placement system
- UPI payment simulation
- Order tracking and delivery address management
- Admin dashboard for managing restaurants, users, and orders

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- MySQL

### Installation
```bash
# Clone the repository
git clone https://github.com/saikumar939851/secure-web-based-food-delivery-management-system.git

# Navigate to project folder
cd secure-web-based-food-delivery-management-system/food_delivery_project

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start the server
python manage.py runserver
```
